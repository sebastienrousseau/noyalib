# Moved

This directory was renamed to [`docs/`](../docs/) in v0.0.31 (Phase 1
of the repository-structure plan). Deep links from documentation
published before v0.0.31 land here; everything lives at the same
relative path under `docs/`.

The `noyafmt.1` / `noyavalidate.1` manpages and the shell completions
moved to the [noya-cli repository](https://github.com/sebastienrousseau/noya-cli),
where the binaries and their generator (`build.rs`, `NOYA_GEN_ASSETS=1`)
live.
