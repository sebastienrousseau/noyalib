# noyalib 0.0.55

Hand-written Highlights for the GitHub release page; the rest of the page
(What's Changed, Checksums, Full Changelog) is generated at release time.

## Highlights ⭐️

* **Every loader enforces every limit**: the borrowed API, the CST, `read_with_config`, the multi-document entry points and skipped values now charge the same budgets as `from_str`, and an alias can no longer build a value deeper than `max_depth`. Hostile input that one path refused and a sibling path accepted is refused everywhere.
* **Linear-time parsing of long lines**: a single long line of flow entries used to cost quadratic time before any budget could refuse it. It is linear again, and a flow collection at the start of a document is streamed instead of buffered whole.
* **Output that reads back as written**: flow strings holding `,` `[` `]` `{` `}`, comments with line breaks, `<<` keys and verbatim tags now round-trip, and `cst::format` never changes what a document means. Formatting hints can no longer be smuggled in through tag names.
* **Breaking parse behaviour**: a verbatim tag `!<x>` now names exactly the tag `x`, and an implicit key holding a flow collection longer than 1024 characters is refused, both as YAML 1.2.2 requires. Schema validation refuses external `$ref`s and compiles patterns with a linear-time engine.
