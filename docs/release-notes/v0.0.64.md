# noyalib 0.0.64

Release date: 2026-11-23.

The rest of the GitHub release page is generated at release time.

## Highlights ⭐️

* **Printable-ASCII scalars skip the byte-level checks**: plain and block scalars made only of bytes `0x20..=0x7E` now pass an eight-bytes-at-a-time screen before the printable checks v0.0.62 added. On x86_64 a 1 KiB flat mapping parses in 295.8k instructions, against 308.7k on v0.0.63 and 293.1k on v0.0.60 (cachegrind, `ubuntu-latest`). What is accepted and refused does not change.
* **Advisory hygiene**: the lockfile moves `url` to 2.5.9 for RUSTSEC-2026-0592, and `.cargo/audit.toml` and `osv-scanner.toml` drop three ignores that matched no crate in any lockfile (#538).
* **In lockstep with noyalib-mcp, noyalib-lsp, noyalib-wasm, noyalib-serde-yaml and noya-cli 0.0.64**, the family's release after 0.0.63.

The Rust 1.89.0 minimum, the default Cargo features, the public API and the parse behaviour are unchanged.
