# noyalib 0.0.59

Hand-written Highlights for the GitHub release page; the rest of the page
(What's Changed, Checksums, Full Changelog) is generated at release time.

## Highlights ⭐️

* **Alloc-only tooling**: CST parsing, formatting and editing, property interpolation, recursive `Rc` anchors, strict string/slice helpers, and recovery work without std. Enabling recovery no longer enables std implicitly; hosted callers must request it when needed.
* **Alloc-only source information**: typed AST fallback and document streams retain `Spanned<T>` locations and error field paths without thread-local storage. Portable behavior tests cover core, accelerated, and combined feature sets; bare-metal gates check the combined portable set. `libm` stays mandatory to preserve existing `--no-default-features` consumers.
* **CST editing, contributed by [Zoo Sky (@zoosky)](https://github.com/zoosky)**: [`grow_value`](https://github.com/sebastienrousseau/noyalib/pull/505) grows a scalar into a typed collection with comment preservation and candidate validation. [Dash-line insertion](https://github.com/sebastienrousseau/noyalib/pull/506) places new fields beneath a sequence item's key, including indentless and nested sequences. Both contributions retain Zoo Sky's commit authorship.
* **`tokio` 1.53.3 for RUSTSEC-2026-0386**: `AsyncFd`'s safe constructors violated I/O safety in tokio 1.53.2, which failed `cargo audit` and `cargo deny` on every build that enables the `tokio` feature. The whole family moves to 1.53.3, the oldest fixed release on the 1.53 line.
* **`jsonschema` 0.60.2 closes a backtracking-limit bypass**: unfinished matches now fail closed under `not` and `patternProperties`. The engine caches unfinished matches across retries, resolving the repeated-work regression that blocked 0.59. Exhaustion reports one shared engine failure; regression tests cover negation, property constraints and 200 repeated or distinct over-limit subjects.
* **Dependencies and CI**: `serde-saphyr` 2.0.0 for the `compare-saphyr` benchmarks, `schemars` 1.2.3, `smallvec` 1.16.4, `arbitrary` 1.5.0, `tokio-util` 0.7.20 and `serde_json` 1.0.154, with their `cargo vet` records; the libyaml differential fuzz targets no longer flag NEL, LS and PS, which YAML 1.1 treats as line breaks and YAML 1.2 does not; and the registry drift net's shim probe and npm job are fixed.
