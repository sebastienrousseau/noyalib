# noyalib 0.0.57

Hand-written Highlights for the GitHub release page; the rest of the page
(What's Changed, Checksums, Full Changelog) is generated at release time.

## Highlights ⭐️

* **Closer to the spec, found by differential fuzzing**: six parse fixes from running noyalib against serde_yaml_ng and libyaml. A plain scalar whose line ends in a space now continues on the next line, an anchor on an empty list item no longer swallows the next item, and folded scalars, escaped line breaks and radix integers follow YAML 1.2 exactly.
* **Typed parses read keys as written**: a tag elsewhere in the document no longer changes how a typed parse spells a key, so a YAML 1.1 `on:` key reaches a struct field named `on`. Duplicate-key checks treat `~` and `null`, or `0x1F` and `31`, as the same key on every path.
* **Safer CST edits**: `cst::format` keeps NEL, NBSP and other Unicode spaces that YAML reads as content, and two fixes from @zoosky make removing or overwriting an alias-valued entry, and recursing into an anchored collection, act on the right bytes.
* **Breaking parse behaviour**: `0X1F` and `0x-1` load as strings, folded scalars keep whitespace-only lines indented past their content, a control character in a comment is an error, empty lines after an escaped break are line feeds, and `- &a\n- x` loads as two items.
