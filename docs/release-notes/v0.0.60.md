# noyalib 0.0.60

Release date: 2026-11-10.

The rest of the GitHub release page is generated at release time.

## Highlights

* **Historical CI and SAST evidence restored**: merged PR #482 had no successful checks after its fork-workflow approval expired. The recovery ran 7,195 tests and CodeQL against its actual source commit, allowing the Scorecard CI-Tests and SAST alerts to close without dismissal.
* **Restricted recovery workflow**: remote and local ancestry checks accept only commits already merged into the default branch. Historical tests start from a trusted checkout, use read-only permissions and no build cache. An isolated job records the actual test outcome against the confirmed source SHA. Twenty-two regression tests cover reporting, ancestry and checkout order.
* **CI maintenance**: the alloc integration build uses rust-cache 2.9.3 (#516), and Markdown lint uses action 25.0.0 (#517).

The core Rust sources, public API, Cargo features and Rust 1.89.0 minimum
remain as in v0.0.59. Existing std and no_std functionality is preserved.
