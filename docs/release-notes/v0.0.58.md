# noyalib 0.0.58

Hand-written Highlights for the GitHub release page; the rest of the page
(What's Changed, Checksums, Full Changelog) is generated at release time.

## Highlights ⭐️

* **Hardened parser, CST and loader boundaries**: `cst::Document` edits re-parse under the document's own configuration, so a YAML 1.1 `yes` can no longer slip past duplicate-key detection, and `!include` and `${...}` expansion now count against `max_total_scalar_bytes`. CST parses and edits run `Policy::check_value`, the `load_all`, `read_with_config` and `no_std` paths run the shared `!include`, `${...}` and policy pipeline, the tokio decoder no longer splits a document at a `---` that ends a read buffer, and `figment::Yaml::file` rejects directories, FIFOs and oversized files before reading.
* **Located unknown and missing field errors**: an `unknown field` or `missing field` rejected by `from_str` now carries its line, column and field path (`deserialization error at line 3, column 10: server.porrt: unknown field: porrt`), as type mismatches already did. A fix from @or1can. `from_value` still returns the bare `Error::UnknownField` and `Error::MissingField`.
* **MSRV is now Rust 1.89.0 across the family**: the core library and every satellite share one minimum supported Rust version ([ADR-0014](https://github.com/sebastienrousseau/noyalib/blob/v0.0.58/docs/adr/0014-shared-msrv-floor.md)); if you are pinned below 1.89, stay on v0.0.57. The `msrv-core` job now builds on 1.89 instead of stable, and `scripts/verify-release-versions.sh` checks all 32 MSRV statements in the tree against `rust-version`.
* **`serde_yaml_ng` retired from dev-dependencies**: it depends on `unsafe-libyaml`, which RUSTSEC-2024-0449 marks unmaintained, so the YAML test suite harness now reads its case files with `yaml-rust2` (the same 406 cases from all 351 files) and `cargo deny` passes with no advisory ignores. `tokio` is at 1.53.2.
