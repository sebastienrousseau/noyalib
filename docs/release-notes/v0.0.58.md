# noyalib 0.0.58

Hand-written Highlights for the GitHub release page; the rest of the page
(What's Changed, Checksums, Full Changelog) is generated at release time.

## Highlights ⭐️

* **Located unknown and missing field errors**: an `unknown field` or `missing field` rejected by `from_str` now carries its source line, column and dotted field path (`deserialization error at line 3, column 10: server.porrt: unknown field: porrt`), matching type mismatches and visitor errors. `from_value` still returns the bare `Error::UnknownField` and `Error::MissingField` variants.
* **MSRV is now Rust 1.89.0 across the family**: the core library and every satellite share one minimum supported Rust version, 1.89.0 ([ADR-0014](../adr/0014-shared-msrv-floor.md)). `shared-msrv-core.yml` now sets `RUSTUP_TOOLCHAIN` and asserts `rustc --version` so `rust-toolchain.toml` can no longer divert the check onto stable, and `scripts/verify-release-versions.sh` checks all 32 MSRV statements in the tree against `rust-version`.
* **`serde_yaml_ng` retired from dev-dependencies**: `serde_yaml_ng` depends on `unsafe-libyaml` (marked unmaintained by RUSTSEC-2024-0449). Following the policy in `deny.toml` to retire rather than exempt unmaintained contenders, the YAML test suite harness now parses case wrappers with `yaml-rust2` (the same 406 cases across all 351 files) and `cargo deny` stays clean without advisory ignores.
* **Dependencies and supply chain**: updates `tokio` to 1.53.2 and pins the `sebastienrousseau/pipelines` reusable workflows to `980375f`, with `cargo vet` audits recorded and unused exemptions pruned.
