# noyalib 0.0.54

Hand-written Highlights for the GitHub release page; the rest of the page
(What's Changed, Checksums, Full Changelog) is generated at release time.

## Highlights ⭐️

* **Reader entry points are bounded**: `from_reader`, `from_reader_with_config`, `from_reader_strict` and `compat::serde_yaml::from_reader` read at most one byte past `max_document_length` and then fail the length budget. They used to buffer the whole source first, so an unbounded or hostile reader could exhaust memory before any limit applied. Follow-up to GHSA-4xcc-23fx-w2wj.
* **Release pages composed from the repository**: the release workflow titles the page `noyalib <version>` and builds it from this file's Highlights, GitHub's generated What's Changed, a SHA-256 of every asset and the Full Changelog link; the version gate requires the file.
