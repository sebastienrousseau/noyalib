# noyalib 0.0.62

Release date: 2026-11-17.

The rest of the GitHub release page is generated at release time.

## Highlights ⭐️

* **A byte order mark is text only where YAML 1.2.2 allows it**: the default profile now refuses a BOM inside plain and block scalars, comments and directive lines (`a: x\u{feff}y` is a parse error), while one still opens the stream or a document prefix. The `serde_yaml` profile reads it as text, as serde_yaml 0.9 does, through the new `ParserConfig::byte_order_marks_in_text` flag. Anchors, tags and `%TAG` directives refuse it in every profile.
* **Closer serde_yaml 0.9 parity**: differential fuzzing against libyaml drove a long list of grammar and compatibility fixes, from under-indented continuation lines and document markers to integer overflow, signed hex and octal, tagged and anchored keys, and error paths spelled `.[1]` at the root. Most of these are breaking; the CHANGELOG lists each one.
* **v0.0.61 folded in**: v0.0.61 was never published, so crates.io moves from 0.0.60 to 0.0.62, carrying every v0.0.61 change. The bench-only `compare-saphyr` feature is gone; the head-to-head benchmarks live in the unpublished `noyalib-compare` crate.
* **In lockstep with noyalib-mcp, noyalib-lsp, noyalib-wasm, noyalib-serde-yaml and noya-cli 0.0.62**, the family's release after 0.0.60.

The Rust 1.89.0 minimum and the default Cargo features are unchanged.
