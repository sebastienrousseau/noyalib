# noyalib 0.0.63

Release date: 2026-11-19.

The rest of the GitHub release page is generated at release time.

## Highlights ⭐️

* **CST inserts read back again**: `cst::Document::insert_entry_value` no longer writes a multi-line string as a `|` block when it holds a C1 control other than NEL, U+FFFE, U+FFFF or a byte order mark, which the v0.0.62 parser refuses there. The edit used to fail its own load-back check and leave the document unchanged; the string now takes the double-quoted spelling, as `to_string` writes it. Reported and fixed by @zoosky (#533, #534).
* **In lockstep with noyalib-mcp, noyalib-lsp, noyalib-wasm, noyalib-serde-yaml and noya-cli 0.0.63**, the family's release after 0.0.62.

The Rust 1.89.0 minimum, the default Cargo features and the parse behaviour are unchanged.
