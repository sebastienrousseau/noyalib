# noyalib 0.0.56

Hand-written Highlights for the GitHub release page; the rest of the page
(What's Changed, Checksums, Full Changelog) is generated at release time.

## Highlights ⭐️

* **No value too deep to drop**: nesting is capped at 256 levels on every path, even with `max_depth` raised, and a `Value` read from another serde format stops there too. Dropping, cloning, printing or serializing a value can no longer overflow a 1 MiB stack.
* **`max_events` holds before buffering**: a long flow-mapping key used to be tokenised whole before the event budget could refuse it. The scanner now gives up as soon as the backlog proves the document is over budget.
* **serde_yaml shim matches upstream on repeated struct fields**: `compat::serde_yaml::from_str` refuses ``duplicate field `k` `` as serde_yaml 0.9 does, where it used to keep the last entry. `load_comments` now applies the default length and backlog limits.
* **Breaking parse behaviour**: input nested deeper than 256 levels is refused whatever `max_depth` says, and the shim refuses documents that repeat a struct field.
